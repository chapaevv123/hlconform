FOR DEVELOPERS / 03

Take the evidence
into your build.

Use the Python CLI for offline replay, portable JSON vectors, and snapshot comparison.

QUICKSTART / PYTHON 3.11READ-ONLY
  1. Clone the repository; Python 3.11 is required.
  2. Capture or load a snapshot.
  3. Check your configuration.
  4. Export vectors or compare snapshots.
git clone https://github.com/chapaevv123/hlconform.git
cd hlconform
python -m hlconform snapshot --network mainnet --out snap.json
python -m hlconform resolve xyz:XYZ100 --snapshot snap.json
python -m hlconform check --config examples/example.toml --snapshot snap.json --json
python -m hlconform vectors --snapshot snap.json --out vectors.json
python -m hlconform diff snap.json snap.json --json

Recorded CLI output excerpt: {"verdict":"VALID","reason_codes":[],"asset_id":110000}. CLI snapshot capture is separate from the browser live check.
